# Seinpy Workspace Customizations

This folder contains project-specific customizations for agents, including custom skills and rules. 

## Structure

- [`/rules/`](file:///home/trevor/repos/seinpy/.agents/rules/) - Place markdown rule files (e.g., `*.md`) here. These rules are automatically loaded by the agent to enforce coding styles, API usage restrictions, or other repository-specific guidelines.
- [`/skills/`](file:///home/trevor/repos/seinpy/.agents/skills/) - Place custom skill folders here. Each skill should have its own directory containing a `SKILL.md` file with name/description YAML frontmatter.
